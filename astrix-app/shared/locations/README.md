# Location art (Journey atmosphere)

Drop each destination's background image here, named by its ForgeDestinations key:

    pale-heart.jpg  dreaming-city.jpg  neomuna.jpg  europa.jpg  throne-world.jpg
    nessus.jpg  edz.jpg  moon.jpg  cosmodrome.jpg

Referenced by `astrix-location-visuals.js` as `/astrix-app/shared/locations/<key>.jpg`.
The image is used as the blurred full-page backdrop when that destination is selected.
A missing file is not an error — the page falls back to that destination's colour
atmosphere (no broken tile). Use Bungie destination art; keep files reasonably sized
(the backdrop is blurred, so ~1600px wide / optimised JPEG is plenty).
