What the DIM loadout viewer does

Paste a dim.gg link, a DIM share ID or a supported DIM loadout URL. The import reads the shared loadout and resolves its item names, icons and descriptions from Bungie definitions.

Inspect the subclass, weapons, armour, mods and any cosmetics included in the share. Missing or unresolved pieces are shown as unavailable, not filled with invented items. Importing a link does not equip anything in Destiny.

How to get a DIM share link

Start with a loadout you have saved in Destiny Item Manager.

  1. Open the Loadouts page in DIM and choose the loadout you want to share.
  2. Use DIM's loadout sharing feature to create a shareable link, then copy the dim.gg URL.
  3. Open Character in ASTRIX PARADOX and choose Import DIM loadout. Paste the link and choose Import loadout.

See DIM's own guide to sharing loadouts. A shared loadout is a separate snapshot. Later edits to your saved DIM loadout do not change that link.

What ASTRIX PARADOX adds

Send the import to Builder to review the build alongside your own inventory. The shared original stays available for comparison with matching items and suggested replacements. A suggested replacement is not a promise of the same effects.

Builder explains supported connections using Bungie item and perk descriptions. Choose an element, objective and activity to guide its recommendations. Review missing items and unresolved details before making changes.

DIM import questions

Is this made by DIM?

No. ASTRIX PARADOX is an independent fan project and is not affiliated with DIM or Bungie.

Do I need to sign in?

You can read this guide without signing in. The current DIM import sits inside the Guardian workspace, which presents a Bungie sign-in screen. The import reads public share data, but Save as PARADOX loadout and Send to Builder require Bungie sign-in and a selected Guardian.

Is it free?

Yes. The DIM loadout import and ASTRIX PARADOX build tools are free.
