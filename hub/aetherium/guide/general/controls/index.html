Open the Skill Bar plan

The Ascent Plan's Skill Bar screen fills this layout with your class's skills, key by key and row by row.

Defiance on Space bar

Every class has Defiance, the skill that breaks crowd control, on Space bar. It never takes a number key.

Macros

There is one macro key and 3 macro presets. Hold the key and the macro uses its skills in order; any skill you press by hand goes first. To change preset you open the Macro window, as there is only one key. In AION1 mode a mouse button cannot be the macro key.

Set the key in Settings Key Settings General Gameplay Macro.

Open the Macro plan

Control modes

There are two control modes and you can swap at any time: AION2 (the default, action style) and AION1 (classic, cursor always on).

Change it in Settings Combat Controls Control Mode. Swap quickly with the / key.

Default keys

The defaults from the global client. Every key can be changed.

Key Settings

Change keys in Settings, Key Settings. It has four tabs, and each tab has its own Reset button that only resets that tab.

Menus with no key

Expedition, Daily Dungeon, Nightmare, Transcendence, Shugo Festival, Abyss, Arena and the Market have no key by default. Give the ones you open often a key in Settings, Key Settings, Menu.

Targeting

Tab locks the target in front of you. In big fights, give Target Hostile Players its own key (for example the middle mouse button) in Settings, Key Settings, General, so Tab does not grab NPCs.

Mouse and camera

There is no mouse sensitivity slider: set the horizontal and vertical camera speeds in Settings, Graphics, Camera/Direction. The game cannot invert the mouse.

Controller

A controller works but is not officially supported, and you cannot change its buttons. It will not work through Steam Remote Play, Steam Link or cloud PCs, because the anti-cheat blocks outside input.
